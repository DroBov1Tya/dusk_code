Added
Two guards against work that goes nowhere, on by default. No progress (`limits.no_progress`): steps in a row that change no project file to a new state, show nothing new, read nothing not read before and pass nothing that failed get a note asking where the turn stands at the 12th (`no_progress_note_at`) and a request for a different plan at the 30th (`no_progress_replan_at`), as `NoProgress` and `NoProgressReplan` notices; notes only, and the turn is then a stall candidate for a judge to come. Goal stalls (`limits.goal_stall`): a goal whose last 3 rounds (`goal_stall_rounds`) left the files its chat changed and its test results as they were pauses for the user, saying what stayed the same; the round cap is unchanged.
