Security
One set of hidden characters now guards every place the core cleans or checks untrusted text: bidi controls and marks, line separators, zero-width and other invisible format characters, and the Unicode tag block. Labels the model shows (`show` blocks, pins) and plugin listings now also refuse left-to-right and right-to-left marks, zero-width spaces, byte order marks and stray tags; emoji joined by zero-width joiners, soft hyphens and subdivision flags still work. Plugin file previews escape every hidden character, and skill change reasons and team task lines drop or mark them.
