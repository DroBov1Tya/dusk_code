The end of a team run counts every gap the completeness check names, whether it writes one "Missing:" line each, a "Missing:" line with a list under it, or a "## Missing" heading with a list; "Missing: nothing" counts none. When its answer cannot be read, the lead is told so and pointed at it instead of hearing that nothing is missing. A review's "Problem: **high**" now counts as high and turns an approval into a fix; "Verdict: approve ✅" reads as an approval, and an approval with a condition ("approve - but fix the docs first") holds the task for the lead. The plan's review chip reads verdicts the same way.
