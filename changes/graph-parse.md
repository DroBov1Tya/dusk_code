Added
The parser of the project graph (design in `docs/project-intelligence.md`, task G1): one Rust file in, the names it defines (functions, methods, types, traits, constants, modules, tests, each with its parent and its lines) and the names it refers to (uses with the first line and a count, imports with their path as written) out. Nothing calls it yet and no switch turns it on; the store and the indexer come next. It reads source as untrusted input: files over 512 KiB, lines over 5,000 bytes, more than 2,000 symbols and parses over 250 ms are skipped with the reason, names are identifiers of at most 128 characters, and the text of strings and comments is never kept. Adds `tree-sitter` 0.27.2 and `tree-sitter-rust` 0.24.2, pinned exactly and linked statically.
