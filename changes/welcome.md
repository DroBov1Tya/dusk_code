The desktop app greets a clean install, one with no provider connected, with one large "I want to connect my own AI" button; it opens a form with only an address and a token, which the core checks and saves as an OpenAI-compatible provider named after the address's host, the token going to the keychain, and the new chat starts on the server's first model. A failed check says plainly whether the address cannot be reached, the token was refused or the server is not OpenAI-compatible: a provider check now carries that kind as `failure` next to its error text. "Not now" hides the screen until the next start, and it does not come back once a provider is connected.
