Added
Two more guards against a stuck turn, both notes only and on by default. Calls going in circles (`limits.loop_cycles`): a run of one to four calls coming round with the same results, or a read giving the same result with nothing changed between, gets a note at the third round and a request for a different plan at the fifth (`cycle_note_at`, `cycle_replan_at`); the reads of one step count as one, and ids, times and durations in results are made alike. Test re-runs (`limits.test_reruns`): a test run with no project file changed since the last run of its runner gets a note naming that run's step and failing tests, then a request for a different plan (`test_rerun_note_at`, `test_rerun_replan_at`), and a run's failing test ids stand for its error in the failure ladder. The protocol (39, oldest still 36) names the rungs of these and of the guards to come: `Cycle`, `CycleReplan`, `TestRerun`, `TestRerunReplan`, `NoProgress`, `NoProgressReplan`, `JudgeRedirect`, `JudgeStop`; the evals count `JudgeStop` as a stop.
