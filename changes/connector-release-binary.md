Workshop connectors can be a program from a pinned GitHub release: one exact tag, one archive per platform named by its SHA-256. Only the official list's own work may bring one. duskcode downloads the archive for this computer from GitHub only, checks its size and SHA-256 before unpacking, takes out only the program into its own versioned folder under the data folder, and starts it from there; removing the connector removes the folder, and an update leaves no old version.
