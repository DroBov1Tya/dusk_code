Implement TTLCache in cache.py. TTLCache(capacity, ttl, clock=time.monotonic) with get(key, default=None), put(key, value), and len(cache). An entry expires ttl seconds after it was last put: at exactly that moment it is gone. get makes an entry the most recently used but does not extend its life; put on an existing key does both. len counts only live entries. When a new key arrives and the cache holds capacity live entries, the least recently used live entry leaves; expired entries never push out a live one. Every operation must take time independent of the number of entries, apart from clearing expired ones.
