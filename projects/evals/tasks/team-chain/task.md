inventory (in this folder) is a stock book in SQLite with three layers to write, in order: each needs the one before it. Write each to the rules below, which say more than the tests do. Do not change the tests or `inventory/__main__.py`.

1. Schema, `inventory/schema.py`, `migrate(conn)` on a `sqlite3` connection. Table `items`: `sku TEXT PRIMARY KEY`, `name TEXT NOT NULL`, `quantity INTEGER NOT NULL DEFAULT 0 CHECK (quantity >= 0)`. Table `moves`: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `sku TEXT NOT NULL REFERENCES items(sku)`, `delta INTEGER NOT NULL CHECK (delta != 0)`, `note TEXT NOT NULL DEFAULT ''`. It sets `PRAGMA user_version = 1` and commits. On a database it already migrated it changes nothing; on one whose `user_version` is above 1 it raises RuntimeError and changes nothing. Done when `python3 -m unittest tests.test_schema` passes.
2. API, `inventory/api.py`, on the schema. `open_store(path)` connects, turns foreign keys on, migrates and returns the connection. `add_item(conn, sku, name)`: the SKU is three upper-case letters, a hyphen and four digits, the whole string; the name, stripped, is not empty; a SKU that exists is refused; each a ValueError. `move(conn, sku, delta, note="")` adds `delta` (a non-zero int, else ValueError) to the item's quantity, records the move and returns the new quantity; an unknown SKU raises KeyError; a move that would take the quantity below 0 raises ValueError and changes nothing. `stock(conn)` returns `(sku, name, quantity)` tuples sorted by SKU; `history(conn, sku)` returns `(delta, note)` tuples oldest first, KeyError for an unknown SKU. Every change is committed before the function returns, and a failed one leaves nothing behind. Done when `python3 -m unittest tests.test_api` passes.
3. Command line, `inventory/cli.py`, `main(arguments)` returning the exit status, run as `python3 -m inventory DB COMMAND ...` and using only the API. `add SKU NAME...` (the words of the name joined by one space) prints `added SKU`. `move SKU DELTA [NOTE...]` prints `SKU: QUANTITY`, the new quantity. `stock` prints a line per item, `SKU  QUANTITY  NAME` with two spaces between and the quantities right-aligned to the widest, or `no items` when there are none. `history SKU` prints a line per move, the delta with its sign (`+5`, `-2`), then a space and the note when there is one. Any error, from the API or from the arguments, prints one line starting with `error: ` on stderr, nothing on stdout, and exits with 2. Done when `python3 -m unittest tests.test_cli` passes.

When all three are done, `python3 -m unittest` passes.
